# Sameer Ilyas Portfolio — HTML, CSS & JavaScript

## Files
- `index.html`: page structure and content
- `style.css`: dark responsive visual design
- `script.js`: current year, contact links, and public GitHub repository loading
- `assets/Sameer-Ilyas-CV.pdf`: add your own CV PDF here

## Run locally
No build tools are required. Extract the folder and open `index.html` in a browser. For the best local development experience, open the folder in VS Code and use the Live Server extension.

GitHub repository loading uses the public GitHub REST API and may be rate-limited. If that happens, the page displays the four curated fallback projects.

## Before publishing
1. Put your PDF CV at `assets/Sameer-Ilyas-CV.pdf`.
2. In `script.js`, replace `CONTACT_EMAIL` and `LINKEDIN_URL`.
3. Verify experience details, descriptions, and all repository URLs.
4. Add live demo links only if you have working demos.

## Deploy
Upload these files to a static host such as GitHub Pages, Netlify, or Vercel. No backend is required.
